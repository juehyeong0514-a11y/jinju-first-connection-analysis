첫차의 연결이 서울 도착 기회를 바꾼다 - v5 (2026-10-08)
AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전 분석 코드

질문: 어느 주거지에서 서울의 같은 목적지에 더 일찍 도착할 수 있고,
첫 운행을 어떻게 조정하면 그 차이가 줄어드는가?
진주20개 대표 지점, 5개 날짜, 강남·서울역·사당을 비교했다.

빠른 결과 검토 (Python 3.10 이상, 키·추가 패키지 불필요)
  python3 analysis/review_results.py
기본300개 비교와 비용, v4 목표시각225행·출발조건540행·버스도착지연450행·
조건부 예약택시360행·상세 대안8행·보행민감도360행·상세 직접보행30행을 검토한다.
원문 시간표의 경로 결합을 다시 수행하는 실행과 구분한다.

전체 경로 재현
RUN_ANALYSIS.txt의1번 절차를 원문 캐시가 포함된 별도 로컬 재현 묶음에서
실행한다. 공개 저장소에는 모든 분석/수집 코드와 집계표가 있다.
원문 캐시는 자동으로 포함하거나 재배포하지 않는다.
캐시 없이 analyze_robustness.py 또는 analyze_decisions.py를 실행하면
입력 파일이 없어 실패한다. 원문 목록과 출처는 DATA_SOURCES.csv 참고.
새 수집은 출처별 이용조건·요일표 확인, 날짜별 공개 배차 대조가 필요하다.

권리와 공개 범위
원자료 이용권한은 각 제공기관 조건을 따른다. 저장소 공개로 원자료의
이용허락을 새로 부여하지 않는다. 전체 원문 캐시·연락처·동의/서명은
공개 저장소에 포함하지 않는다. .env는 사용자 로컬에서만 관리한다.

제출 문서 형식 수정 (계산 v5 유지)
공식 붙임2의10개 항목 순서와 왼쪽 항목/오른쪽 내용 표 구조로 수정했다.
출처·참고문헌을 포함한 본문5쪽, 결과 그림2개, 코드 링크를 유지했다.
build_official_report.py는 python-docx/reportlab/pdftoppm과 별도 로컬 묶음의
공식 양식 변환본·원본 로고가 필요하다. 공개 저장소에 해당 원문을 추가하지 않았다.
check_official_report.py는 python-docx/pypdf로 완성 문서의 항목·출처·그림·쪽수를 검사한다.
필요한 DOCX/PDF는 로컬 묶음에 있으며 저장소만으로 문서 검사는 실행되지 않는다.
build_robust_report.py는 설명형·검증부록만 생성하며 공식 제출본을 덮어쓰지 않는다.
