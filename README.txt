첫차의 연결이 서울 도착 기회를 바꾼다
AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전 분석 코드

질문: 어느 주거지에서 서울의 같은 목적지에 더 일찍 도착할 수 있고,
첫 운행을 어떻게 조정하면 그 차이가 줄어드는가?
진주 20개 대표 정류장, 5개 날짜, 강남·서울역·사당을 비교했다.

빠른 결과 검토 (Python 3.10 이상, 키·추가 패키지 불필요)
  python3 analysis/review_results.py
300개 공개 집계표와 독립적인 일행/좌석 비용 계산을 확인한다.
원문 시간표의 경로 결합을 다시 수행하는 실행과는 구분한다.

전체 경로 재현
RUN_ANALYSIS.txt의 1번 절차를 원문 캐시가 포함된 별도 로컬 재현 묶음에서
실행한다. 이 공개 저장소에는 모든 분석/수집 소스코드와 집계 비교표를
올렸으며, 원문 캐시는 자동으로 포함하거나 재배포하지 않는다.
캐시 없이 analyze_robustness.py를 바로 실행하면 입력 파일이 없어 실패한다.
새 수집은 출처별 API 이용조건·요일표를 확인하고, KOBUS 공개 배차는
해당 날짜 화면에서 수동 대조해야 한다. 원문 목록은 DATA_SOURCES.csv 참고.

주요 결과와 해석
- 평일 두 핵심 표본 강남 도착11:00→09:27, 93분 앞당김.
- 105분 일찍 출발하므로 여정은12분 길다. 시간절약 편익이 아니다.
- 지선 첫차50방향을 복원하고, 좌표·순서로 추천127개를 추가했다.
  여전히 미대응344개가 남아 완전한 네트워크 최적해를 주장하지 않는다.
- 토요일 효과는 지선 배정 경계로 공개. 일요일 고정04:45안은 실패한다.
- 첫 서울행50분 전 출발: 평일04:40, 토04:50, 일04:20.
- 주택1,825호와 행정동 인구를 실제 수혜 인구·새벽 서울행 수요로 읽지 않는다.
- 가족·기존 일행 택시 동승, 연계 좌석 올림, 취소·불참을 비용에 반영했다.

검증과 의존성
최신 내부 검사36,105개 및 별도 이전 버전292개 통과.
숫자는 계산 내부 일관성의 검사 범위이며 실제 운행 성공률의 증거가 아니다.
주 분석과 빠른 검토는 표준 Python. 보고서는 reportlab과 한글 TTF,
공식 철도 엑셀 전처리는 openpyxl을 사용한다.

AI 활용
OpenAI Codex: 공개자료 수집·정류장 대응·시간표 계산·반례 점검·코드·문서 작성.
주요 지시: 같은 서울 목적지의 이른 도착과 첫 운행 개선, 철도 대안 포함,
공개자료로 규모·누락·요일/목적지·비용 보강. 참가자가 최종 자료와 해석을 확인한다.

권리와 공개 범위
원자료의 이용권한은 각 제공기관의 조건을 따른다. 저장소 공개로 원자료의
이용허락을 새로 부여하지 않는다. 전체 원문 캐시·연락처·참가 동의/서명은
공개 저장소에 포함하지 않는다. .env는 사용자의 로컬에서만 관리한다.
