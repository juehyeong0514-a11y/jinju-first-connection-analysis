진주 새벽 첫 연결 분석 - 공개자료 검증판 v3 (2026-10-08)

최신: 20개 대표 정류장, 5개 날짜, 강남/서울역/사당, 3개 지선배정 가정.
본문5쪽+참고문헌1쪽, 검증부록9쪽. v1/v2 코드는 비교용 이전 버전입니다.

1. 캐시로 최신 분석 재현 (Python 3.10 이상, API 키·네트워크·추가 패키지 불필요)
   python3 analysis/repair_transfer_aliases.py
   python3 analysis/analyze_robustness.py
   python3 analysis/check_robustness.py
   결과: outputs/robust/analysis.json, calendar_destination_comparison.csv,
         alias_audit.json, recovered_transfer_paths.json, validation.json
   180개 시나리오·300개 지점/날짜/목적지 비교·8,100개 비용 조합.
   시간순서·전철 열차번호·지선 경계·코드대응·비용 등 내부 논리 검사.
   검사 통과는 실제 운행 성공·실측 시간·신규 수요·계약 견적을 입증하지 않습니다.

2. PDF 재생성 (reportlab 필요)
   python3 analysis/build_robust_report.py
   output/pdf/jinju_first_connection_analysis.pdf (본문5쪽+참고문헌)
   output/pdf/jinju_first_connection_evidence.pdf (별도 검증부록9쪽)
   macOS AppleGothic 사용. 다른 OS는 KR_FONT 환경변수에 한글 TTF 경로 지정.

   최신 재현 작업에서 실행하지 마세요.

3. 원자료 추가 수집 (캐시 재현과 별개, 네트워크·자료 갱신 필요)
   collect_calendar.py: BIS 토/일 상세표와 요일 누락 응답 별도 보관.
   collect_alias_times.py: 코드대응 추천 경로의 BIS 예상 통과시각.
   collect_expanded_samples.py: 노선·추천 경로·시간 예상.
   collect_public_demand.py: ITS 월별 공개 집계.
   refresh_tago.py YYYYMMDD: TAGO 새 날짜 수집. API 키는 .env에만 보관.
   API 키 값·인증키가 든 URL·쿠키·브라우저 세션 파일은 공유하지 않습니다.
   새 날짜 분석은 해당 날짜의 시내버스/장거리/전철도 함께 갱신해야 합니다.
   주말은 3/4, 전철은 SAT/END. 임시 공휴일·배차 변경은 별도 확인 필요.
   KOBUS 4개 추가 날짜×3개 허브의 09시 이전 배차는 공개 UI 수동 대조.
   자동 미래 TAGO 빈 응답을 무운행으로 해석하지 않습니다.

4. 개선안과 해석의 중요 조건
 - 04:00 이후 출발, 외부 보행 합계 최대20분, 지역 승차 여유2분.
 - 승강장 이동5분+장거리 승차 여유10분, 서울 보행/환승은 계획 가정.
 - 기존 50방향 제외 규칙을 폐기. 각 지선 첫차는 상세 노선번호 묶음에 존재.
 - strict=해당 지선 요약 첫/막, matched=동일 비고 후보, optimistic=전체 묶음.
   비고 매칭은 확정 지선 배정이 아니며 낙관 경계를 승객 안내에 쓰지 않음.
 - 미대응 추천471개 중 좌표3m이내+정류장 순서+유일방향으로127개 복원.
   344개는 남음, 핵심 두 지점22개. 모든 환승/완전망 최적해를 주장하지 않음.
 - 평일 핵심 두 지점 강남11:00→09:27, 93분 앞당김. 105분 일찍 출발해
   여정은12분 늘어남. 도착 기회와 이동시간 절약을 구분.
 - 날짜별 첫 서울행50분 전 풀에버 출발: 평일04:40,토04:50,일04:20.
   LH10+6분, 승차장+15분. 22.5분 주행+10분 이동+15분 승차 여유도2.5분 잔여.
   이는 조건 검토이며 실제 운행 성공률을 관측한 것은 아님.
 - 기존04:45고정안은 일요일05:10편을 놓침. 출발은 승차권/요일에 맞춰 확정.
 - 토요일은 강남82~102분/서울역78~102분/사당82~99분 배정 경계로 표시.
   300개 비교 중36개가 지선 배정 가정에 영향. 전체 망 경계가 아님.
 - 10/17 혁신 첫차 잔여9석은 조회 당시 값. 연계12석이 장거리12석 확보 아님.
 - 미래 철도는 공식 매일운행 KTX204/382/206 보완. 일반열차 전체 확보 아님.
 - 관련 공동주택1,825호, 행정동33,698명/12,904세대(7/1 기준)를 구분.
   실제 수혜 가구·신규 서울행 수요·단지 전 동의 접근성으로 일반화하지 않음.
 - 9월 승차 시간/일/노선 합계1,983,808건 일치, 행정동3,697건 차이는 보존.
 - 가족·기존 일행 동승만 택시 대수에 반영. 모르는 일행을 합치지 않음.
 - 좌석 초과는 연계 차량 수 올림. 늦은 불참은 계약한 연계비용을 줄이지 않음.
 - 견적3~12만원/대, 8·12·16석, 택시3석, 취소/불참 요금은 가정 격자.
   실제 계약·면허·보험·새벽 운행·회송 원가는 확인 전 미확정.
